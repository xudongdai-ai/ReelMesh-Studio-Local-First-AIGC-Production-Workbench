# Portfolio snapshot and current production boundary

This repository is the existing public workbench snapshot. It is not a mirror of the current
private production system. Current internal providers, credentials, company assets, private media,
production infrastructure and proprietary changes are not added in this portfolio update.

Public workflow: project/specification → visual assets → storyboard → generation tasks
→ human approval → editing → export. React / Node.js / SQLite / Electron support the public snapshot.
Automatic music/edit execution may use the separate ShortDramaAgent / editor skill workflow;
this does not mean a cloud music API is built into this repository.

The company use statement is applicant-reported. No company-wide efficiency, audience outcome,
character-consistency improvement or formal user-study result is claimed here.
Synthetic file-matching and short local subtitle-render exercises shown in the portfolio are
engineering demonstrations, not measurements of company productivity.
