# 批量生图工作流

这套工作流把当前项目的制作规范接到真实图片服务上：

1. 在“生图连接”中配置一个 OpenAI 兼容的图片接口。
2. 在“制作规范”里选择人物、场景、服装、道具或图片提示词规范。
3. 输入自然语言或带字段的需求，系统抽取人物、场景、服装、道具、群演、动作、镜头、光线和负面限制。
4. 选择每批 1–8 张，点击“抽取并生成”。系统会同时保存制作规范、资产和生成任务。
5. 结果进入四图审核；失败或不满意时点击“重做”，会追加新的重生轮次，不覆盖旧结果。

## 婚礼工作流

“婚礼制作”已经接入同一条生图链路。故事卡中的新人、婚期、相识经历、重要片段、家人与朋友、风格方向、必须保留和明确避开内容，会先进入“婚礼影像生图规范”进行抽取。

- 第 7 步“重点生图”固定生成 3 张定调图。
- 第 8 步“批量生图”固定生成 4 张结果图。
- 婚礼事实会写入提示词，人物、婚纱礼服、仪式场地、关键道具、亲友和动作会分别抽取，明确避开内容会进入负面限制。
- 两个步骤都进入现有生成队列，可继续重生、审核和选定资产；未配置真实服务时只创建待接入任务，不伪造图片。

## 接口约定

服务地址可以是云端地址，也可以是本机开源服务。接口需要支持：

```text
POST /v1/images/generations
```

请求为 OpenAI 风格的 JSON，包含 `model`、`prompt`、`negative_prompt`、`size`、`n` 和可选 `seed`。响应需要在 `data` 数组中返回 `b64_json` 或 `url`。应用会把返回图片下载并保存到本机，未配置或失败时不会生成假图。

## 命令行批量提交

输入文件可以是字符串数组，也可以是对象数组：

```json
[
  {
    "name": "焚决主角",
    "archiveCategory": "人物",
    "aspectRatio": "3:4",
    "request": "人物：二十岁男主，黑色短发，眉骨有旧伤\n服装：深灰旧战袍\n动作：侧身回头，警惕凝视"
  },
  {
    "name": "雨夜城门",
    "archiveCategory": "场景",
    "aspectRatio": "16:9",
    "request": "场景：深夜雨中的古城门\n光线：冷青雨幕，门内一盏暖灯"
  }
]
```

已配置过连接后，直接提交：

```bash
node scripts/batch-image-generation.mjs \
  --account 账号 --password 密码 \
  --project 项目ID --input prompts.json --count 4
```

首次也可以在命令行内配置服务：

```bash
node scripts/batch-image-generation.mjs \
  --account 账号 --password 密码 \
  --project 项目ID --input prompts.json \
  --image-endpoint https://你的服务地址 \
  --image-model 你的图片模型 \
  --image-key 访问密钥
```
